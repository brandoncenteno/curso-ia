# Curso IA Aplicada y Segura

Mi recorrido aprendiendo ingeniería de IA aplicada y segura: desde la API de Claude hasta agentes, RAG, MCP, guardrails y evaluaciones.

## Cómo correrlo

1. Crea y activa un entorno virtual: `python -m venv venv`
2. Instala las dependencias: `pip install -r requirements.txt`
3. Copia `.env.example` como `.env` y agrega tu propia API key de Anthropic
4. Ejecuta: `python hola.py`
